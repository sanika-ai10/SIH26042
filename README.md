# AI-Powered Vernacular Pedagogy and Real-Time Translation Tool

**SIH26042 | Smart India Hackathon 2026**

An AI-powered, offline-first educational solution designed to support mother-tongue-based primary education by enabling Hindi-to-Santhali translation and voice-based learning support.

---

## Problem Statement
**AI-Powered Vernacular Pedagogy and Real-Time Translation Tool for Mother Tongue-Based Primary Education**  
The project aims to reduce language barriers between Hindi-speaking teachers and Santhali-speaking students by providing real-time translation and educational content in the student's mother tongue (Santhali using Ol Chiki script).

---

## Proposed Solution
The system combines lightweight speech recognition, machine translation, text-to-speech synthesis, and curriculum-aligned educational resources into a low-latency, offline-capable pipeline.
